## 📊 DB 스키마 설계

### 1. ai_consultations (AI 상담 테이블)
```sql
CREATE TABLE ai_consultations (
  id SERIAL PRIMARY KEY,
  session_id VARCHAR(255) UNIQUE NOT NULL,
  user_name VARCHAR(100),
  user_email VARCHAR(255),
  user_phone VARCHAR(50),
  category VARCHAR(100), -- 키워드 카테고리
  initial_query TEXT NOT NULL, -- 초기 질문
  consultation_type ENUM('search', 'keyword', 'form') DEFAULT 'search',
  status ENUM('active', 'completed', 'abandoned') DEFAULT 'active',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. ai_messages (대화 내역 테이블)
```sql
CREATE TABLE ai_messages (
  id SERIAL PRIMARY KEY,
  consultation_id INTEGER REFERENCES ai_consultations(id) ON DELETE CASCADE,
  role ENUM('user', 'assistant', 'system') NOT NULL,
  content TEXT NOT NULL,
  timestamp TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 3. consultation_categories (상담 카테고리)
```sql
CREATE TABLE consultation_categories (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  keywords TEXT[], -- 관련 키워드 배열
  form_template JSONB, -- 폼 템플릿 정보
  color VARCHAR(20) DEFAULT '#3B82F6',
  icon VARCHAR(50),
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
